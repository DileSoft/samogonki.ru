# Самогонки — архивный сайт

Реконструкция официального сайта игры «СамоГонки» (K-D LAB / 1С) по снимку из веб-архива:

<https://web.archive.org/web/20050208180029/http://www.samogonki.ru/>

Проект собран на **Vite + React + TypeScript**. Внешний вид повторяет оригинальный тёмный интерфейс 2002 года: шапка с логотипом и языковым переключателем, верхнее меню с круглыми иконками, левая колонка с наездниками и навигацией, оранжевые заголовки, новости, колонка скриншотов и «битриксовый» подвал. При этом вёрстка адаптивная: на планшетах и телефонах навигация перестраивается, колонка скриншотов уходит вниз, меню становится компактным.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Структура

```text
public/assets/        архивные GIF/JPEG-материалы и скриншоты
public/data/          большие архивы: игры, чемпионаты, форум, рейтинг
public/replays/       файлы повторов .msr
src/components/       шапка, меню, подвал, галерея, лайтбокс, новости
src/pages/            страницы сайта
src/data/             основной контент в JSON
src/styles/           глобальные стили и адаптивность
```

Маршруты: главная, новости и отдельная новость, скриншоты, об игре, вселенная, создатели, где купить, контакты, файлы, онлайновый сервер, игры сервера и карточка игры, чемпионаты, повторы, форум и тема форума, анкета игрока, карта сайта.

## Данные

Контент не зашит в компоненты:

| Файл | Что внутри |
| --- | --- |
| `src/data/site.json` | меню, логотипы, подвал, бегущая строка |
| `src/data/home.json` | вступление и блоки главной |
| `src/data/news.json` | новости 2002 года |
| `src/data/screenshots.json` | галерея и скриншоты для главной |
| `src/data/game.json` | «Коротко об игре», факты и режимы |
| `src/data/universe.json` | хроники СамоГа |
| `src/data/team.json` | создатели и благодарности |
| `src/data/buy.json`, `contacts.json` | покупка и контакты |
| `src/data/files.json` | материалы для скачивания |
| `src/data/online.json`, `forum.json` | онлайн-сервер и описание форума |
| `src/data/games.json` | метаданные сервера и финал 17-го чемпионата |
| `public/data/games-archive.json` | 969 восстановленных игр с участниками и финишной статистикой |
| `public/data/championships-archive.json` | 101 игра с «Чемпионат» в названии |
| `public/data/players-archive.json` | 135 позиций рейтинга и 111 анкет игроков |
| `public/data/forum-archive.json` | 347 тем, 250 обсуждений и 2427 сообщений |
| `public/data/replays.json` | индекс 1072 файлов повторов |
| `public/replays/*.msr` | сырые записи повторов онлайн-игр |

Чтобы добавить новость, достаточно дописать объект в `news.json` — список на главной, страница новостей и соседние ссылки обновятся автоматически.

## Источники материалов

- Тексты и компоновка — архивные страницы `samogonki.ru` 2002–2005 годов.
- Логотипы, иконки, фоны, иллюстрации — Wayback Machine.
- Игры сервера, карточки игр, рейтинг и анкеты — архивы `/games/`, `/games/players.asp`, `/games/game_info.asp`, `/games/player_profile.asp`.
- Повторы — архивные ответы `/game-on-line/default.asp?ID=…` (файлы `.msr`).
- Форум — архивные `/forum/`, `/forum/list.asp` и `/forum/read.asp`.
- Финал 17-го чемпионата — `/games/game_info.asp?ID=3665`.
- Скриншоты игры — официальная страница переиздания *Spanking Runners* в Steam (те же миры и персонажи, современное разрешение).

## Что не восстановлено

- Из 1435 игр сервера отдельные архивные страницы есть только у 1022; удалось получить 969. Для остальных сохранились лишь названия в общих списках и профилях.
- Из 1185 ID повторов в веб-архиве удалось скачать 1072 файла.
- Из 116 анкет игроков удалось получить 111.
- Форум: 347 тем известно по спискам, полные сообщения есть у 250 тем; у 97 тем сохранились только заголовки, автор и дата последнего ответа. Восстановлено 2427 сообщений.
- Не сохранились аватары, вложения, личные сообщения, чат и полная серверная авторизация. Повторы `.msr` не проигрываются в браузере — нужен оригинальный клиент игры.
- Полная турнирная сетка всех чемпионатов в архиве отсутствует; восстановлены 101 игра с «Чемпионат» в названии, новости и финал 17-го чемпионата.

Архивный сайт восстановлен в образовательных и исторических целях. Права на игру и материалы принадлежат их правообладателям.
